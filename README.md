# Bash Manager

Графическое приложение для управления Bash-скриптами: группы, редактор с подсветкой, запуск **локально** и на **удалённых Linux-серверах по SSH**, с **шифрованием SSH-доступов** мастер-паролем.

Стек: **Electron · Node.js · TailwindCSS · ssh2** (vanilla JS, без фреймворков — работает полностью офлайн).

---

## Возможности

- 📁 Папка со скриптами = набор **групп** (подпапки). Названия скриптов и папок — на любом языке, включая русский.
- ✏️ Встроенный **редактор** с подсветкой синтаксиса Bash, номерами строк, автосохранением по `Ctrl/Cmd+S`.
- ▶️ Запуск скриптов **локально** (`child_process`) или **по SSH** (`ssh2`) с потоковым выводом и ANSI-цветами.
- 🔐 **Шифрование SSH-доступов**: scrypt (вывод ключа) + AES-256-GCM. Открытые пароли никогда не сохраняются на диск.
- 🗝 **Мастер-пароль** не хранится в папке со скриптами и не попадает в git. Опционально — «запомнить на устройстве» через `safeStorage` Electron (средства ОС: Keychain/DPAPI/libsecret), данные лежат вне репозитория.
- 🛡 **Верификация ключа хоста (TOFU)**: при первом подключении отпечаток показывается пользователю, сохраняется; при смене ключа подключение блокируется (защита от MITM).
- 🧾 Формы аргументов перед запуском, переменные окружения, лимит времени исполнения, принудительная остановка.
- 📜 История запусков с полным логом вывода (в папке `.bash-manager/runs/`, рекомендована к `.gitignore`).
- 🔍 Поиск по группе, избранное, метки, тёмная/светлая тема, авто-блокировка хранилища по таймауту неактивности.
- 🌐 Интерфейс на **английском и русском**: язык определяется автоматически по языку ОС, переключается в настройках без перезапуска (меню приложения переводится тоже).
- 🪟 Окно свободно масштабируется (до 400×300), интерфейс адаптируется под размер: на узком окне панели перестраиваются, группа выбирается списком; размер, положение и состояние «развёрнуто» запоминаются между запусками.

## Быстрый старт

```bash
npm install        # electron, ssh2, tailwindcss
npm run build:css  # собрать стили (один раз; tailwind.css уже вкоммитлен)
npm start          # запустить приложение
```

Сборка установочных пакетов (Linux: AppImage/deb, Windows: NSIS/portable) описана в [BUILD.md](docs/BUILD.md).

При первом запуске:
1. **Выберите папку** со скриптами (или скопируйте `examples/` куда-нибудь и укажите её).
2. Придумайте **мастер-пароль** (минимум 8 символов) — создастся хранилище.
3. Создавайте скрипты кнопкой «+», настраивайте SSH в «Настройках скрипта», запускайте.

Проверка криптоядра и прочего:

```bash
npm test           # 12 юнит-тестов шифрования
npm run smoke      # headless-запуск окна (нужен Xvfb на Linux без дисплея)
```

## Структура папки со скриптами

```
<корневая папка>/
├── Серверы/                        # группа = подпапка
│   ├── group.json                  # настройки группы (общий SSH, env, описание)
│   ├── обновление_системы.sh
│   ├── обновление_системы.sh.meta.json
│   └── проверка_дисков.sh
├── Бэкапы/
│   ├── group.json
│   └── бэкап_проекта.sh (+ .meta.json)
└── .bash-manager/
    ├── vault.json                  # соль + верификатор мастер-пароля (НЕ секрет)
    └── runs/                       # журналы запусков — добавьте в .gitignore!
```

### `group.json`

```json
{
  "title": "Бэкапы",
  "description": "Резервное копирование",
  "ssh": {
    "host": "srv.example.com",
    "port": 22,
    "auth": "password",
    "login": "enc1:...",        # зашифровано приложением
    "password": "enc1:...",
    "privateKeyPath": "",
    "passphrase": "",
    "hostKey": "SHA256:..."     # отпечаток ключа хоста (TOFU)
  },
  "env": { "KEEP_DAYS": "14" },
  "defaults": { "timeoutSec": 600 }
}
```

### `<скрипт>.sh.meta.json`

```json
{
  "id": "uuid",
  "title": "Бэкап проекта",
  "description": "…",
  "tags": ["бэкап"],
  "favorite": true,
  "runOn": "remote",            // local | remote
  "inheritSsh": true,           // наследовать SSH группы
  "ssh": { },                   // свой SSH-доступ (если не наследуется)
  "args": [
    { "flag": "--dir", "label": "Каталог", "default": "/etc", "required": true }
  ],
  "env": { "DEBUG": "0" },
  "timeoutSec": 600
}
```

## Как устроена безопасность

| Компонент | Реализация |
|---|---|
| Вывод ключа из пароля | `crypto.scryptSync` (N=32768, r=8, p=1), случайная соль 16 байт |
| Шифрование полей | AES-256-GCM, случайный IV 12 байт на поле, формат `enc1:base64(iv‖tag‖ct)` |
| Проверка пароля | HMAC-SHA256 ключа (сравнение `timingSafeEqual`), сам ключ не хранится |
| Хранение «запомненного» пароля | `electron.safeStorage` (Keychain/DPAPI/libsecret) в `userData`, **вне репозитория** |
| SSH-ключи хостов | TOFU + блокировка при смене отпечатка |
| Renderer | `contextIsolation`, `sandbox`, строгий CSP, нет inline-обработчиков, нет `nodeIntegration` |
| Секреты в renderer | дешифрованные логин/пароль **никогда** не покидают main-процесс |

Что важно знать:

- **Забытый мастер-пароль невозможно восстановить.** SSH-доступы придётся ввести заново.
- `vault.json` (соль + верификатор) и зашифрованные поля в `.meta.json` — не секреты, но обладатель них может перебирать слабые пароли офлайн. Используйте длинный пароль (индикатор стойкости в приложении).
- Логи запусков могут содержать чувствительный вывод — кнопка «Добавить служебные пути в .gitignore» в настройках добавит `.bash-manager/runs/`.
- Смена мастер-пароля (в настройках) перешифровывает **все** сохранённые SSH-доступы.

## Скрипты npm

| Команда | Назначение |
|---|---|
| `npm start` | Запуск приложения |
| `npm test` | Юнит-тесты криптоядра и репозитория/раннера |
| `npm run smoke` | Headless-проверка запуска окна |
| `npm run selftest` | Сквозной E2E-тест через IPC (хранилище, запуск, шифрование, смена пароля) |
| `npm run build:css` | Пересборка стилей Tailwind |
| `npm run build:css:dev` | Сборка стилей в режиме наблюдения |

## Структура кода

```
electron/
├── main.js            # окно, меню, single-instance, smoke-режим
├── preload.js         # contextBridge API (единственная точка доступа renderer)
├── ipc.js             # все IPC-обработчики, сессия хранилища, авто-блокировка
├── crypto/vault.js    # scrypt, AES-256-GCM, верификатор, оценка пароля
└── core/
    ├── repo.js        # сканирование/запись скриптов и метаданных
    ├── runner.js      # локальный и SSH-запуск, реестр процессов, лимиты времени
    ├── ssh.js         # ssh2: exec через stdin, экранирование, TOFU host key
    ├── history.js     # журнал запусков
    └── settings.js    # настройки приложения
src/
├── input.css          # Tailwind + темы + подсветка + ANSI
└── renderer/
    ├── index.html     # оболочка + CSP
    ├── app.js         # интерфейс (состояние, рендер, модалки)
    ├── editor.js      # редактор с подсветкой Bash
    └── ansi.js        # ANSI→HTML конвертер
test/vault.test.js     # тесты криптоядра
examples/              # демо-скрипты с русскими названиями
```
